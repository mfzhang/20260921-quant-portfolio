# Quant Portfolio — Mean Reversion

미국 대형주 유니버스에서 **통계적 차익거래**와 **횡단면 평균회귀**를 결합한 퀀트 포트폴리오 백테스트 프로젝트입니다.

---

## 가설

> 단기적으로 공정가치(또는 상대가치)에서 벗어난 가격·스프레드는 평균으로 회귀하며,  
> 그 수렴 구간에서 **시세차익(mean-reversion alpha)** 을 체계적으로 취할 수 있다.

| 슬리브 | 가설의 구현 | 시그널 |
|--------|-------------|--------|
| **Statistical Arbitrage** | 섹터·사업이 유사한 페어의 스프레드는 공적분 관계를 따르며, z-score 이탈 후 수렴한다 | 롤링 헤지비율 스프레드, \|z\| ≥ 2.5 진입 / ≤ 0.5 청산 / ≥ 4 손절 |
| **Cross-Sectional Mean Reversion** | 횡단면상 단기 과잉반응(급등·급락)은 수일 내 반전된다 | 5일 수익률 하위 20% 롱 / 상위 20% 숏, 5일 리밸런싱 |

두 슬리브를 비교·검증한 뒤, **본선은 Statistical Arbitrage**로 둔다.  
매크로 쇼크(바스켓 급락·vol 스파이크)와 북 고점 대비 −12% 드로다운 시 즉시 플랫하는 가드를 붙인다.  
Cross-Sectional MR은 위성·비교용으로 유지한다.

**6. 손실 원인 진단 (`diagnose_stat_arb.py`) → 페어 북 구조 변경 (`strategies/pair_book.py`)**
- 진단: 비용 전에도 CAGR −4.1%, 비용 후 −11.8% (turnover 49x), 북 순노출 평균 36% (시장 중립 아님)
- turnover의 최대 원인은 매일 북 전체 L1 재정규화, 다음은 β 매일 재헤지
- 기존 z-score는 날마다 다른 β로 만든 스프레드를 이어 붙여 계산 → 같은 날 정합 z와 부호까지 다른 경우 존재
- 새 페어 북: 로그 가격 스프레드, 이동창 회귀 잔차 z, 진입 시 β·평균·표준편차 고정, 페어당 1/24 고정 비중,
  재선정 때 열린 포지션 유지, 한쪽 다리 편출 시 양쪽 청산 (`STATARB_BOOK = "pair_book"`)
- 결과(원본 북, 매매 시작 이후): turnover 49x → 9.4x, 순노출 36% → 3%, MDD −62% → −15%, CAGR −11.8% → −2.4%
- 시간손절 없음(회귀까지 대기)과 비교: 학습 구간은 개선, 보류 구간은 악화 → 기본값(2×HL) 유지
- 학습 구간 손실 섹터 제외: 섹터 순위가 학습/보류 구간에서 뒤집혀 신뢰 불가 → 미채택
- 남은 문제: 손절(|z| ≥ 4)이 거래의 58%로 익절보다 많음 → 2.5σ 이탈이 회귀보다 확대되는 경향 (신호 자체의 한계)

**6-1. 진입 시점·이탈 강도 비교 (`run_entry_experiment.py`, 미채택)**
- 진입 시점: 첫 돌파(cross) vs 꺾임(turn: |z|가 전날보다 줄어든 첫날) vs 재진입(recross: |z|가 2.5 아래로 복귀)
  - 승률 36% → 45% → 50%, 손절 비율 58% → 45% → 36%로 개선되지만 거래당 비용 전 손익은 −18 → −29 → −32bps로 악화
  - 기다리는 동안 회귀 폭 일부를 놓쳐 이익이 줄어듦. 비용 후 CAGR은 세 방식 모두 약 −2.4% (학습/보류 구간 순위도 엇갈림)
- 이탈 강도(진입 전 최대 |z|): 첫 돌파 진입에서는 이탈이 클수록 손절 비율 상승(보류 구간 50% → 70% → 86%)
  → 큰 이탈은 기회보다 관계 붕괴 신호. 재진입 방식은 강도와 무관하게 손절 비율 약 35%
- 어떤 진입 방식·강도 구간도 학습·보류 구간 모두에서 비용 후 플러스가 아님. 거래당 비용(왕복 30bps)을 넘는 엣지 없음

| 후보 그룹 | 비용 후 CAGR (전체 / 학습 / 보류) | MDD | turnover | 평균 총노출 | 회차당 페어 |
|-----------|-----------------------------------|-----|----------|-------------|-------------|
| 섹터 (현재) | −2.4% / −2.7% / −2.1% | −15.3% | 9.4x | 0.21 | 20.1 |
| 하위 업종 | −1.5% / −1.6% / −1.3% | −10.0% | 6.7x | 0.15 | 14.9 |

- 섹터 선정 페어 중 같은 하위 업종 페어(약 30%)가 다른 하위 업종 페어보다 오히려 나쁨 (보류 구간 −28 vs −16bps)
- 결론: "더 비슷한 사업 = 더 안정적인 공적분"이라는 가설은 보류 구간에서 확인되지 않음. 기본값은 섹터 유지

**9. 스프레드 추세 필터 (`run_trend_experiment.py`, `trend_max_r2`, 미채택)**
- 가설: 이탈이 꾸준한 추세(관계 이동)의 일부면 회귀하지 않고 손절로 끝난다
- 규칙(사전 고정, 스윕 없음): 진입 직전 120일(룩백 2배) 스프레드의 선형 추세 R² ≥ 0.5이고 방향이 이탈과 같으면 진입 안 함
- 결과: 비용 후 CAGR −2.4% → −2.0% (학습 −2.7 → −2.2%, 보류 −2.1 → −1.8%), turnover 9.4 → 7.6x
  - 개선은 거래 수·노출 감소 효과. 노출당 손실은 −0.116 → −0.119로 오히려 소폭 악화
  - 거래당 비용 전 손익은 학습 −16 → −17bps, 보류 −21 → −22bps, 손절 비율 58% 그대로
- 추세 점수 구간별(기준선 거래): 강한 추세(R² ≥ 0.5) 거래는 학습·보류 모두 약 −2bps로 오히려 나은 편이고, 약한 추세 구간(0~0.5)이 가장 나쁨. 구간 순위도 학습·보류에서 엇갈림
- 결론: 추세 여부로 손절을 가려낼 수 없음. 필터는 기본 off

**10. 뉴스성 점프·최근 회귀 속도 필터 (`run_signal_filter_experiment.py`)**
- 규칙(사전 고정, 스윕 없음)
  - 점프: 진입 전 5일 안에 어느 한 종목이라도 시장(동일가중) 대비 초과수익률이 직전 60일 변동성의 4σ 이상이면 진입 안 함
  - 회귀 속도: 진입 직전 120일 스프레드의 AR(1) 반감기가 선정 당시 반감기의 2배 초과이거나 회귀 성향이 없으면 진입 안 함

| 진입 필터 | 비용 후 CAGR (전체 / 학습 / 보류) | MDD | turnover | 노출당 손실 | 거래당 비용 전 (학습 / 보류) |
|-----------|-----------------------------------|-----|----------|-------------|------------------------------|
| 없음 | −2.4% / −2.7% / −2.1% | −15.3% | 9.4x | −0.116 | −16 / −21bps |
| 점프 | −2.4% / −3.1% / −1.7% | −15.4% | 7.4x | −0.140 | −36 / −24bps |
| 회귀 속도 | −1.7% / −1.7% / −1.7% | −11.6% | 7.7x | −0.098 | −5 / −17bps |
| 점프 + 회귀 속도 | −1.5% / −1.9% / −1.2% | −10.0% | 6.0x | −0.109 | −20 / −13bps |

- 점프 필터: 학습 구간에서 악화 → 미채택. 학습 구간에서는 4σ 이상 점프 뒤 진입이 가장 좋았고(거래당 +36bps) 보류 구간에서는 중간이라 일관성 없음
- 회귀 속도 필터: 학습에서 개선 → **채택** (`STATARB_HL_MAX_RATIO = 2.0`). 보류 구간에서도 CAGR·노출당 손실·거래당 손익 모두 개선되어 방향 확인. 다만 손절 비율(약 58%)은 그대로이고 비용 후는 여전히 마이너스
- 구간별 진단(기준선 거래): 최근 반감기 비율 1~2배 구간이 두 기간 모두 가장 좋고(+27 / +5bps), 0.5배 미만(최근 회귀가 지나치게 빠름)은 두 기간 모두 크게 나쁨(−50 / −47bps). 보류 구간을 본 뒤 나온 관찰이라 하한 추가는 새 데이터로 검증하기 전에는 적용하지 않음

**11. 저부채·저PER 종목으로 후보 제한 (`run_value_filter_experiment.py`, 미채택)**
- 데이터: SEC EDGAR companyfacts(무료). 재선정일까지 제출된 공시만 사용(PIT). 탈락 종목 34개 CIK는 `pit_cik_overrides.py`로 보완
- PER = 수정 전 종가 ÷ 최근 12개월 희석 EPS (수정주가를 쓰면 분할·배당만큼 과거 PER이 낮게 나와 왜곡). 공시 이후 분할은 보정
- 절대 기준(부채총계/자본 < 50%, PER < 10)은 185종목 중 0~2개만 남아 페어 구성 불가 → 상대 기준으로 대체
- 규칙(사전 고정): 재선정일마다 지수 편입 종목 중 부채비율 ≤ 중앙값 **그리고** PER ≤ 흑자 기업 중앙값. 자본잠식·적자·공시 없음은 제외 → 24~35종목 통과

| 후보 | 비용 후 CAGR (전체 / 학습 / 보류) | MDD | turnover | 평균 총노출 | 회차당 페어 | 노출당 손실 |
|------|-----------------------------------|-----|----------|-------------|-------------|-------------|
| 전체 종목 (현재) | −1.7% / −1.7% / −1.7% | −11.6% | 7.7x | 0.17 | 20.1 | −0.098 |
| 저부채·저PER | −0.0% / −0.1% / +0.0% | −0.8% | 0.7x | 0.02 | 2.4 | −0.018 |

- CAGR이 0% 근처인 건 페어가 회차당 2.4개뿐이라 자본의 2%만 투자된 결과(전략 규모가 사실상 사라짐)
- 거래당 비용 전 손익: 학습 −2bps(24건), 보류 +43bps(35건). 표준편차가 260~370bps라 t값 0.96(보류), 전체 59건 비용 후 t = −0.13 → 우연과 구분 불가
- 결론: 표본이 너무 작아 판단 불가. 기본값 변경 없음

**11-1. 상대강도(백분위 순위) 점수로 완화 (`run_value_filter_experiment.py`, 미채택)**
- 점수 = 부채비율 백분위 순위와 PER 백분위 순위의 평균(낮을수록 좋음, 적자·자본잠식·데이터 없음은 최하위). 재선정일마다 상위 비율만 후보로 사용

| 후보 | 통과 종목 | 비용 후 CAGR (전체 / 학습 / 보류) | MDD | 노출당 손실 | 거래당 비용 전 (학습 / 보류) | 거래 수 |
|------|-----------|-----------------------------------|-----|-------------|------------------------------|---------|
| 전체 종목 (현재) | 185 | −1.7% / −1.7% / −1.7% | −11.6% | −0.098 | −5 / −17bps | 633 |
| 교집합 (11번) | 28 | −0.0% / −0.1% / +0.0% | −0.8% | −0.018 | −2 / +43bps | 59 |
| 시장 전체 상위 50% | 82 | −0.2% / +0.2% / −0.5% | −3.6% | −0.015 | +42 / +3bps | 354 |
| 섹터 내 상위 50% | 81 | −1.1% / −0.7% / −1.5% | −8.0% | −0.102 | +7 / −36bps | 400 |
| 섹터 내 상위 75% | 122 | −1.3% / −0.9% / −1.7% | −9.3% | −0.087 | +10 / −28bps | 555 |

- 학습 구간 최선은 시장 전체 상위 50%(거래당 +42bps, 표준오차 26)였지만 보류 구간에서 +3bps(표준오차 23)로 엣지가 사라짐 → 비용 후 마이너스
- 같은 점수를 섹터 안에서 매기면 학습·보류 모두 기존과 비슷하거나 나쁨. 즉 시장 전체 버전의 차이는 기업 가치 수준이 아니라 섹터 구성 변화(금융·유틸리티·리츠처럼 부채비율이 구조적으로 높은 섹터가 빠지고 IT·에너지 비중 증가) 효과로 보임 — 앞서 불안정했던 섹터 제외 실험과 같은 성격
- 결론: 기준을 완화해도 비용을 넘는 엣지는 보류 구간에서 확인되지 않음. 기본값 변경 없음

**12. 가설 변경: 우량주 눌림목 매수 (`run_quality_dip_experiment.py`, `strategies/quality_dip.py`, 미채택)**
- 가설: 재무가 튼튼한 기업의 단기 급락은 일시적이라 회복한다 (롱온리, 시장 노출 있음)
- 규칙(사전 고정): 매월 말 ROE·부채비율·이익수익률 백분위 평균 점수 상위 1/3이 후보. 5일 수익률 ≤ −2σ면 매수, 20일 이동평균 회복 또는 20거래일 후 매도. 종목당 10%, 최대 10종목

|------|---------------------------|--------|-----|------|----------------|

| 지수 편입 종목 동일가중 | 11.3% / 11.1% / 11.5% | 0.68 | −36.8% | 0.90 | 100% |

- 눌림목 거래 812건: 승률 61%이지만 거래당 비용 후 +0.2%(학습) / +0.4%(보류), 표준오차 0.4~0.5%로 우연과 구분 불가. 회복 청산은 평균 +3.6%, 20일 시간 청산은 평균 −10.2%로 큰 손실 몇 건이 이익을 상쇄
- 2020년 급락 때 계속 떨어지는 종목을 연달아 사서 MDD −48%. turnover 19x로 비용만 연 약 2.8%
- 재무비율 바스켓도 동일가중·SPY보다 낮음: 이 기간은 대형 성장주가 시장을 이끌어 이익수익률(저PER) 기울기가 불리했음
- 결론: 이 기간에 CAGR 10% 이상은 재무비율 선별이 아니라 시장 노출(베타)에서 나옴. 재무비율로 시장을 이기는 근거는 확인되지 않음

**13. 순주식발행 롱숏 (`run_issuance_experiment.py`, `strategies/issuance.py`, 미채택)**
- 가설: 증자·주식보상으로 주식 수를 늘린 기업은 이후 부진하고, 자사주 매입으로 줄인 기업은 강하다
- 신호: 최근 분기(또는 회계연도) 가중평균 희석주식수의 전년 대비 증가율. 같은 공시의 전년 비교값을 써서 분할 왜곡 없음, 월말까지 제출된 공시만 사용
- 규칙(사전 고정): 매월 말 증가율 하위 30% 매수, 상위 30% 공매도, 동일가중, 롱 0.5 / 숏 0.5. 주 버전은 섹터 안에서 순위(섹터 중립)

| 2018-02 ~ 2026-09, 비용 포함 | CAGR (전체 / 학습 / 보류) | 비용 전 CAGR | Sharpe | MDD | t값 | 베타 |
|------|---------------------------|--------------|--------|-----|-----|------|
| 섹터 중립 (주 버전) | −0.9% / −0.4% / −1.6% | +0.2% | −0.27 | −10.0% | −0.79 | −0.03 |
| 시장 전체 | +0.3% / −0.3% / +1.2% | +1.3% | 0.08 | −13.5% | 0.25 | 0.03 |

- 롱(주식 수 감소) CAGR 11.8% vs 숏(주식 수 증가) 11.2% (섹터 중립): 차이 연 0.6%로 비용(turnover 2.4x)을 넘지 못함
- 경기 국면: 섹터 중립은 2022 금리 인상 약세장 +2.9%, 시장 하락월 연 +0.7%로 약하게 방어적이지만 회복·상승장(2022-10 이후 −6.8%)에서 잃음. 시장 전체 버전은 반대로 상승장 +, 하락월 연 −5% → 섹터 쏠림 효과
- 결론: S&P500 대형주·이 기간에서는 경기 순환 전체에 걸쳐 통하는 엣지 없음 (학계에서도 이 효과는 소형주에서 강하고 대형주에서는 약해짐)

**14. F-스코어 보유 vs 자사주·증자 이벤트 레버리지 (`run_fscore_experiment.py`)**
- F-스코어(피오트로스키 9항목, 최신 10-K의 당기·전기 비교). 증자 항목을 순주식발행으로 대체: 주식 수 감소 2점, 증가 0점 → 만점 10점
- FS 보유: 매 분기 F-스코어 8점 이상(월평균 36종목) 동일가중 보유
- 이벤트 레버리지(비교): FS 보유 + 공시에서 주식 수가 전년 대비 2% 이상 감소하면 종목당 +2% 추가 매수(최대 +50%), 2% 이상 증가하면 종목당 −3% 공매도(최대 −75%), 공시 다음 날부터 63거래일. 뉴스 데이터가 없어 SEC 공시일로 대체. 차입 매수 금리 연 3%, 대차 연 1.5%

| 2018-02 ~ 2026-09, 비용 포함 | CAGR (전체 / 학습 / 보류) | Sharpe | MDD | 베타 |
|------|---------------------------|--------|-----|------|
| FS ≥ 8 보유 | 11.1% / 9.8% / 13.1% | 0.66 | −32.2% | 0.92 |
| FS ≥ 8 보유 + 이벤트 레버리지 | 7.3% / 4.7% / 11.6% | 0.46 | −32.2% | 0.87 |
| 이벤트 매매만 | −2.2% / −3.7% / +0.2% | −0.33 | −24.8% | −0.05 |
| 지수 편입 종목 동일가중 | 10.4% / 9.7% / 11.6% | 0.63 | −36.8% | 0.90 |
| SPY | 14.0% / 9.4% / 21.7% | 0.78 | −33.7% | 1.00 |

- FS 보유는 CAGR 10% 이상이지만 동일가중 대비 초과수익 연 0.7%(추적오차 5.2%, t = 0.37)로 통계적 의미 없음. MDD는 4.6%p 작음
- 이벤트 레버리지는 오히려 연 3.8%p 손해: 자사주 매입 종목 롱·증자 종목 숏이 이 기간 함께 역행(이벤트 매매만 연 −2.2%), 레버리지가 손실을 키움
- 결론: CAGR 10% 이상은 F-스코어 선별보다 시장 노출에서 나옴. 레버리지 이벤트 매매는 미채택

## 백테스트 주의사항

- 룩어헤드 완화: **당일 종가 비중 → 익일 수익률**에 적용
- 거래비용: commission + slippage(bps)×turnover, 숏 노셔널에 연환산 borrow fee/252
- 유니버스: 그날 S&P500 멤버만 매매 가능(pitindex). 상장폐지 종목의 과거 시세는 무료 소스에서 빠질 수 있음
- 종목별 hard-to-borrow·배당·세금·유동성 한도는 아직 단순화되어 있음
- 과거 성과는 미래 수익을 보장하지 않음
